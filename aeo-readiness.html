AEO Readiness Score

Pick a page and this live-fetches its HTML, this site's robots.txt and llms.txt, then runs nine checks — indexability, canonical hygiene, AI-crawler access, structured data validity, title/description/H1 presence, content substance and llms.txt coverage — and rolls them into a single readiness score. Same honest, real-fetch approach as Crawler Lens, no mocked results.

How the score works

Each of the nine checks below is worth one point. AI-crawler access counts as a single check but is only awarded if every bot in the sample set (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended) is allowed under this site's robots.txt for that path. 90%+ reads as Ready, 60–89% as Mostly Ready, below 60% as Needs Work. This is a hygiene checklist, not a ranking prediction — it says nothing about whether an answer engine will actually choose to cite the page.
